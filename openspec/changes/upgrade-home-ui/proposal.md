# Proposal

## Why

首页当前使用较重的红棕深色渐变，视觉偏压抑，且头部与导航栏残留「老王烤肠」品牌字样需要移除；同时顾客在首页看不到自己有订单待取货，售罄商品从菜单中直接消失而非显示「已售罄」，顾客无法感知剩余数量与售卖进度。

## What Changes

- **首页配色升级**：由红棕深色系改为更轻快的奶油暖色系（杏色/奶咖/奶油黄为主，红棕降级为按钮等点缀色），覆盖首页背景、头部、卡片、底部已选条、导航栏与 tabBar 颜色。
- **移除品牌字样**：删除首页头部的「老王烤肠」文字区（整个头部文字区简化掉），首页导航栏标题与全局导航栏标题改为「今日菜单」，与 tabBar 命名一致。
- **首页待取货提醒（新增）**：已登录顾客打开首页时，若存在「待取货」状态订单，在菜单上方展示提醒条（含取货码与订单数），点击跳转「我的订单」。顾客停留首页期间定时轮询（30 秒）自动刷新提醒。仅提示「待取货」状态；未登录或无待取货订单时不展示。
- **商品卡片剩余数量 / 已售罄（新增，含后端改造）**：
  - 后端菜单接口不再过滤售罄商品，改为返回每个商品的真实剩余库存（`sku.stock - lockStock`，无 SKU 时用 `product.stock`）。
  - 前端商品卡片展示剩余数量（如「仅剩 N 份」），剩余为 0 时图片遮罩显示「已售罄」并禁用加单按钮。

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

> 说明：`stall-menu-ordering` 与 `stall-order-lifecycle` 两个能力的主 spec 尚未归档（仍在 `vendor-stall-miniapp` 等在途变更的 delta 中），故本变更沿用项目现行约定，以 ADDED 需求形式在 delta 中补充，归档时与主 delta 一并合并。

- `stall-menu-ordering`: 「今日菜单展示」需求变更——菜单不再服务端过滤售罄商品，改为返回含售罄商品及真实剩余库存的完整列表；商品卡片展示剩余数量，售罄商品以「已售罄」样式展示且不可加单；首页头部去除品牌字样，导航栏标题为「今日菜单」，整体采用奶油暖色视觉。
- `stall-order-lifecycle`: 新增「首页待取货提醒」需求——已登录顾客在首页可见其待取货订单提醒（含取货码），可跳转订单列表。

## Impact

- **后端**：`mall/mall-portal` — `StallMenuServiceImpl`（菜单不过滤售罄、返回真实剩余库存）、`StallMenuController` 返回模型（新增剩余库存字段或在 PmsProduct 上以扩展字段承载）。
- **前端**：`mall-app-web/src` — `pages/index/index.vue`（配色重构、头部简化、待取货提醒条、卡片库存展示与售罄态）、`pages.json`（首页及全局导航栏标题与颜色、tabBar 颜色）、`types/stall.ts`（菜单项类型补充剩余库存字段）、`apis/stall.ts`（复用现有订单列表接口，无新增）。
- **兼容性**：菜单接口响应结构变化（新增字段、售罄商品不再被过滤）对现网旧版小程序前端向前兼容——旧版会把售罄商品渲染为普通商品，但加单时后端仍有库存校验兜底；取货码与订单流程不受影响。
