# Spec Delta

## Purpose

补充顾客端首页的待取货订单提醒契约。本能力（stall-order-lifecycle）的主 spec 尚未归档（仍在 `vendor-stall-miniapp` 变更的 delta 中），故以 ADDED 需求形式补充，归档时与主 delta 一并合并。

## ADDED Requirements

### Requirement: 首页待取货提醒

已登录顾客打开菜单页（首页）时，若其存在「待取货」状态的摊位订单，首页 SHALL 在菜单区上方展示待取货提醒条，内容至少包含待取货订单数量与该订单的取货码；点击提醒条 SHALL 跳转到「我的订单」页。未登录顾客或无「待取货」订单时 SHALL NOT 展示提醒条。SHALL NOT 依赖消息推送；顾客停留在首页期间，系统 SHALL 定时轮询其待取货订单，使提醒条的出现与消失 SHALL NOT 依赖手动刷新，轮询 SHALL 仅在首页前台展示期间进行。仅「待取货」状态触发首页提醒，其他进行中状态（已付款/制作中）SHALL NOT 触发。

#### Scenario: 有待取货订单的顾客打开首页

- **WHEN** 已登录顾客存在 1 笔「待取货」订单（取货码 N017）并打开首页
- **THEN** 菜单上方展示提醒条，含取货码 N017 与待取货标识，点击后跳转「我的订单」页

#### Scenario: 无待取货订单

- **WHEN** 已登录顾客没有任何「待取货」状态订单并打开首页
- **THEN** 首页不展示待取货提醒条，菜单正常展示

#### Scenario: 未登录顾客打开首页

- **WHEN** 未登录顾客打开首页
- **THEN** 首页不展示待取货提醒条，不触发任何需要登录的查询报错，菜单正常展示

#### Scenario: 制作中订单不触发提醒

- **WHEN** 已登录顾客仅有「制作中」状态订单并打开首页
- **THEN** 首页不展示待取货提醒条

#### Scenario: 停留首页期间出餐

- **WHEN** 顾客停留在首页，其某笔订单被摊主完成出餐（进入「待取货」状态）
- **THEN** 无需任何操作，提醒条在下一个轮询周期内出现

#### Scenario: 停留首页期间取货完成

- **WHEN** 顾客停留在首页，其待取货订单被摊主确认取货完成
- **THEN** 提醒条在下一个轮询周期内自动消失
