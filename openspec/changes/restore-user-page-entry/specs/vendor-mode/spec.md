# Spec Delta

## Purpose

补充摊位小程序中"我的"页面与摊主入口的可达性契约：本变更依赖的两个能力（stall-menu-ordering、vendor-mode）尚未归档（仍在 `vendor-stall-miniapp` 变更的 delta 中），故以 ADDED 需求形式补充，归档时与主 delta 一并合并。

## ADDED Requirements

### Requirement: 我的页面入口

系统 SHALL 提供"我的"页面（账号状态、摊主模式入口、设置、通知），SHALL 将其注册为 tabBar 第三项（今日菜单 + 我的订单 + 我的）：顾客与摊主 SHALL 能通过底部 tabBar 的"我的"标签进入该页面。（2026-10-22 修订：原"SHALL NOT 恢复为独立 tabBar"的约束由用户决定解除，入口方案从订单页导航栏改为 tabBar 第三项。）

#### Scenario: 从 tabBar 进入我的页面

- **WHEN** 顾客或摊主点击底部 tabBar 的"我的"标签
- **THEN** 切换进入"我的"页面，页面正常展示用户信息与功能入口

#### Scenario: 未登录状态进入我的页面

- **WHEN** 未登录用户进入"我的"页面
- **THEN** 页面正常打开并展示游客状态，功能入口按登录态显隐，不报错不白屏

### Requirement: 摊主模式入口可达

摊主模式入口 SHALL 保持既有的隐藏设计：在"我的"页面连点头像 5 次进入管理员登录，登录成功后"我的"页面显示"摊主模式"入口，点击进入摊主模式页面。"我的"页面不可达 SHALL 导致摊主模式整体不可用，因此入口可达性随本变更一并恢复。

#### Scenario: 摊主进入摊主模式

- **WHEN** 已登录摊主会话的用户打开"我的"页面
- **THEN** 页面显示"摊主模式"入口，点击后进入摊主模式页面，可操作商品开关与订单队列

#### Scenario: 隐藏入口触发管理员登录

- **WHEN** 未有会话的用户在"我的"页面连续点击头像 5 次
- **THEN** 跳转管理员登录页，登录成功后返回并可进入摊主模式
